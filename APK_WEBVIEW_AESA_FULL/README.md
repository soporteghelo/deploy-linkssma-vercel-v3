# Motor de Apps Android (Android Studio)

Proyecto base para compilar un APK que muestra una webview configurable.

- El nombre de la app, logo, URL y otros datos globales se configuran en `app/src/main/res/values/config.xml`.
- El logo debe copiarse como PNG a las carpetas mipmap.

## Estructura
- build.gradle, settings.gradle, etc.
- app/src/main/java/com/[paquete]/MainActivity.java
- app/src/main/res/layout/activity_main.xml
- app/src/main/res/mipmap-xxxhdpi/ic_launcher.png
